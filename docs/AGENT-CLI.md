# Agent 命令行实施记录

2026-10-28。`pnpm agent:cli` 已接入正式服务 SDK，提供会话、任务、事件和来源授权的命令行操作。它不启动服务、不创建凭据，也不在本地复制模型或工具执行器。

## 连接与凭据

服务需事先运行。默认地址为 http://127.0.0.1:4320，使用 AGENT_URL 覆盖；地址校验沿用共享客户端，仅允许本机 HTTP 或 HTTPS。

凭据默认读取数据目录中的 service-owner.json。AGENT_CREDENTIAL_FILE 可指定已有设备凭据 JSON，只需包含 token 字段。CLI 不接受命令参数形式的令牌，不打印凭据内容或异常堆栈。帮助及参数检查不读写凭据，读取失败会明确返回错误。

## 命令

| 命令 | 行为 |
| --- | --- |
| status | 查询正式服务状态 |
| conversations | 分页列出当前身份可见会话 |
| new "标题" | 创建拥有者直聊会话 |
| send <conversationId> "正文" [clientMessageId] | 提交一次消息，先输出重试标识，再输出服务接受结果 |
| run <runId> | 查询保存的执行状态及结果 |
| cancel <runId> | 显式取消执行 |
| watch [afterEventId] | 输出该位置之后的事件，逐行 JSON；Ctrl+C 停止观察 |
| sources <conversationId> | 查看当前目标会话的授权来源 |
| grant-sources <targetId> <sourceId> ... | 整体替换跨会话来源列表，需管理拥有者权限 |
| clear-sources <conversationId> | 显式清空跨会话授权列表 |

多词正文和标题使用 shell 引号。来源授权不是追加操作；提交的列表会替换全部来源，服务继续检查会话归属、来源数量与权限。

## 重试与取消

CLI 发送前输出 clientMessageId，网络结果不确定时仍可取得该标识。以相同正文和标识重试会命中服务端去重，不自动提交第二条逻辑消息。GET 的有限网络重试沿用 SDK，POST 不暗中重试。

watch 可以保存最后收到的 eventId，在重新连接时作为参数传入。位置失效返回 event_resync_required，应重新查询快照后观察；本期不提供自动断线重连。

Ctrl+C 只结束当前命令或事件观察。已经接受的任务继续运行，需 cancel 才取消远程任务。取消期间已经发出的请求可能已经被服务接受，应保留输出的提交标识查询或重试。

输出数据为逐行 JSON，错误写到标准错误。成功或用户取消退出码为 0，请求或凭据错误为 1，参数错误为 2。当前为独立命令式客户端，不提供交互式聊天循环。

## 验证与后续

测试使用正式 API 测试夹具和假模型，覆盖凭据缺失、帮助、参数校验、会话与来源授权、网络丢失后的显式去重重试、取消后防止迟到写入。独立 CLI 进程验证认证和事件流，确认 Ctrl+C 不取消服务端任务。

后续可基于同一 SDK 增加交互式界面和来源管理 UI。记忆语义提取、共享会话、账号绑定和云端部署需单独确定数据权限，不在命令行内另建一套执行流程。

验证结果：核心测试 77 项、客户端测试 6 项和核心类型检查通过；新增 CLI 定向测试 5 项包含真实本地 HTTP、SSE 和子进程。`pnpm agent:cli --help` 通过，命令用 node --import tsx 启动，帮助不依赖 tsx 启动器的本地 IPC 监听。浏览器 6 项、客户端类型检查及 Web 构建已在四期通过，本次没有修改 UI 或协议。

测试日志位于忽略目录 `artifacts/cli/`，没有调用真实模型或使用用户数据库。文档已核对标题、术语、凭据信息和实际命令。
