# 通用 Agent 执行核心实施记录

2026-10-27，面向仓库维护者。一期已提交为 `73433ec`；类型检查及 24 项宿主、API、锁安全定向测试通过。HTTP/SSE（服务端持续推送事件）与真实进程身份测试需要在沙箱外运行，原先的权限错误已排除。

## 已实施的职责

| 模块 | 职责 |
| --- | --- |
| `agent/contracts.ts` | 中立会话消息、模型消息、工具描述与异步执行契约 |
| `agent/executor.ts` | 模型与工具循环、预算、取消检查、工具结果处理 |
| `cognitive/models/deepseek-adapter.ts` | 一次模型调用及供应商协议转换 |
| `tools/agent-tools.ts` | 时间、骰子和可选搜索的注册；每次执行独立维护搜索预算和来源 |
| `channels/console/generator.ts` | 工作台提示与已提交历史的准备、执行结果和来源组合 |
| `runtime/service/host.ts` | 保留排队、并发、120 秒任务总超时和持久化；历史类型改用中立契约 |

执行器默认最多 3 轮工具调用、总计 8 次调用；每项工具结果最多 2000 字符、等待最多 8 秒。最终回复保留 1500 个字符，推理最多 32000 字符且通过独立回调返回。模型适配器保留每次请求 30 秒网络超时，RunHost 管理任务总截止时间。

取消会结束执行器等待，并在每次工具调用前后检查；忽略取消信号的实现返回后也不能触发后续工具或提交结果。已启动工具产生的外部副作用无法由执行器撤销，工具实现仍须遵守取消信号。工具异常和无效参数返回可解释的资料，供应商错误细节不进入模型上下文。

搜索最多执行 2 次，返回失败或空结果时给出明确说明。来源只从返回的有效 URL 中取得；搜索资料先缩减成有效 JSON，再交给执行器执行通用结果长度限制。增加异步工具只需注册工具实现，无需修改供应商适配器。

## 验证与边界

新增假模型测试覆盖文本、多轮及多工具、未知工具、工具失败、无效参数、轮次与数量预算、工具超时、模型及工具等待期间取消。工作台集成测试覆盖供应商工具协议、来源、失败和空结果；原有任务测试继续覆盖取消后防止迟到写入与推理历史隔离。

旧 QQ 生成器仍使用原实现；本期没有迁移 QQ 数据、提取长期记忆或改变人格授权边界。工作台不再调用旧 QQ 生成器及其会话上下文。未来渠道应复用通用执行器，第三期再处理身份、记忆和人格能力。
