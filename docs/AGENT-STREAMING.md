# Agent 真实流式输出实施记录

2026-10-29，面向本仓库维护者。Web 和交互式 CLI 已接入模型真实增量输出：模型片段到达后即可看到未提交草稿，最终回答仍由服务统一检查并保存。模型、工具、认证、取消和来源授权继续使用原有执行流程。

## 使用与前置条件

按根 README 启动正式服务，启用并配置模型后，从 Web 发送消息，或运行 `pnpm agent:cli chat`。不增加流式开关、数据库迁移或本地凭据副本。未配置模型仍返回原有错误。

供应商适配遵循 [DeepSeek Chat Completion 官方协议](https://api-docs.deepseek.com/api/create-chat-completion/)：设置 `stream: true`，读取 SSE（服务端持续发送事件）的正文增量、工具片段和结束标记。服务装配默认提供输出回调，因此实际聊天使用此路径；不需要输出回调的旧调用保留一次性响应兼容。

## 数据与提交边界

| 层次 | 行为 |
| --- | --- |
| 模型适配器 | 逐片段解析正文；按索引拼接工具名和参数，完整回合结束后才交给执行器；推理单独收集，不作为草稿广播 |
| 通用执行器 | 收集当前回合正文，沿用 1500 字符上限；进入工具回合时清除上一回合草稿，继续沿用工具预算和取消信号 |
| 常驻任务服务 | 仅在活动任务内存中保存完整草稿快照；检查任务归属、来源有效性和取消状态；完整结果通过最终检查后才写入问答历史 |
| SDK（共享服务客户端） | 提供当前快照和异步订阅；校验数据类型、任务标识和终态；连接提前结束作为错误，释放连接与读取器 |
| Web | 用完整快照替换草稿，完成后展示最终结果并与历史消息去重；防止迟到的轮询把终态改回运行中 |
| 交互式 CLI | 展示标为未提交的增量片段；终端输入与提示符保持可用；最终只把服务返回的完成结果标为助手回答 |

草稿不进入 SQLite、持久事件或下一轮模型历史。服务重启后未完成任务沿用 interrupted 状态，已丢弃的草稿不会重播，也不自动重新生成。原有推理保存规则不变，推理不参与下一轮历史。

## 任务输出接口

`GET /api/v1/runs/:id/output` 沿用正式认证、拥有者归属和浏览器来源检查。默认返回 JSON；带 `Accept: text/event-stream` 时返回 `run.output` 事件，数据结构相同：

```ts
interface RunOutput {
  run: Run;       // 原有任务状态与最终结果
  text: string;   // 当前完整草稿；仅 running 状态可非空
  sequence: number;
}
```

事件内容是完整快照。客户端重连后直接替换当前文字，无需拼接历史片段，也无需保存草稿游标。`sequence` 仅帮助识别当前进程内的草稿变化，不是持久事件游标；原有 `/events` 和 `eventId` 保持生命周期用途。

服务每 100 毫秒检查订阅身份、来源及任务状态，有变化才发送，15 秒无变化发送心跳。输出订阅与原事件订阅共享 64 个连接上限；关闭连接不会取消任务，写入阻塞或认证失效会关闭订阅。终态发送空草稿及最终任务状态后关闭连接。

SDK 使用 `client.output(runId, signal)` 读取快照，使用 `for await (const snapshot of client.watchRun(runId, signal))` 订阅。主动取消订阅使用 AbortSignal（可传递取消通知的对象）；取消任务仍调用原有 `client.cancel(runId)`。

## 失败、取消与权限变化

- 模型必须给出有效回合结束原因和 `[DONE]`。截断、非法帧、无效工具片段、超限内容和连接提前结束均不能形成完成回答；模型请求的 30 秒与任务的 120 秒限制继续生效。
- 取消、失败、超时、任务被取代或来源授权变化后，服务返回空草稿，禁止迟到片段与最终结果写入历史。来源读取失败同样不能视为授权通过。
- 来源检查发生在每个模型片段、工具执行、输出快照读取和最终提交前。即使模型暂时没有新片段，已连接的订阅也会触发来源有效性检查。
- 设备撤销、会话失效或页面来源不受允许后，订阅不能继续输出；撤销设备不等于取消拥有者的服务端任务，其他授权设备仍可观察。
- 搜索失败或无结果后暂停正文预览，沿用既有搜索提示与引用规则；不会先把未经核实的后续正文当成最终答案展示。

已送达客户端的文字无法撤回。Web 会清空失效草稿；CLI 的终端滚动记录可能保留旧片段，因此始终标明未提交，并显示清除或中断提示。使用者应以服务端 completed 结果和消息历史为准。

## 断线与客户端范围

Web 断线后先清空不确定草稿，最多自动连接 3 次，每次间隔 1 秒；失败后可显式重新连接。切换会话、服务或设备身份会终止旧订阅，迟到数据不能覆盖当前会话。

CLI 不自动重新提交或恢复订阅。输出中断后保留任务标识，用 `/resume <runId>` 读取最新快照并继续观察；`/cancel` 才取消任务。`/exit`、Ctrl+C 和输入结束只停止本地观察。SSE 订阅不再误用单次请求的 15 秒超时。

流式首次交付未包含多行输入编辑；后续已实现多行编辑和终端草稿原位刷新，见[CLI 多行编辑记录](AGENT-CLI-EDITOR.md)。后台观察、多供应商适配、持久草稿回放及推理流式展示仍未实现，桌面与移动客户端仍暂停迭代。
