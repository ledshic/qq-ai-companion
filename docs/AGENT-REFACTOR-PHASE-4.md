# 旧 QQ 归档与活动服务清理

2026-10-28。旧 QQ 渠道、群聊调度、事件记忆及相关素材已退出活动服务和默认检查。保留认证服务、通用执行器、可选来源记忆、工具、Web、SDK 及原数据兼容。

## 归档与保留范围

| 范围 | 处理 |
| --- | --- |
| 旧渠道、参与判断、暖场、发送、事件记忆、人格计划、识图及表情 | 112 个旧源码和测试文件移入 legacy/qq/src，清单见归档 manifest |
| 旧配置、素材、Compose 及 QQ 文档 | 移入 legacy/qq，原脚本与环境副本供查阅 |
| 模型协议转换与 HTTP 请求 | 单份实现移到 src/infrastructure/models，活动工作台改用该路径 |
| 时间、骰子、搜索、取消、进程锁 | 保留中立实现；搜索供应商及来源规则不变 |
| 旧库兼容测试 | 用历史表结构夹具验证原记录保留，不再导入旧会话存储实现 |
| 旧群聊行为测试 | 随源码归档，不再纳入默认测试；不承诺旧行为兼容 |

归档前服务与进程管理路径共引用 26 个生产源码文件。归档按这份依赖集合保留共享实现，没有复制完整核心，也没有从活动路径引用归档。边界测试检查相对导入解析、核心依赖方向、默认命令与编译范围。

## 默认入口与依赖

`pnpm dev` 和 agent:serve 启动同一正式服务。agent:start 经进程锁检查后启动服务子进程，agent:status 与 agent:stop 查询或停止本机宿主。原 napcat、bot:*、回放及素材索引入口从默认脚本移除。

默认环境只保留服务所需的模型、历史、并发、记忆和表达配置；原环境在归档中供参考。根依赖不再包含 ws、sharp 和 @types/ws，锁文件通过离线、只更新锁文件的命令同步，没有下载或安装新工具。

TypeScript 默认仅检查 src，显式排除 legacy；核心测试仅扫描 src。浏览器和客户端检查维持原命令。归档不是可直接运行的独立项目，恢复方式见[归档说明](../legacy/qq/README.md)。

## 数据与协议兼容

不删除或迁移数据库、data 目录、拥有者凭据及原 QQ 表。保留 bot.lock 路径及 API 的 qq 字段，服务固定为 disabled。项目包名暂不改动，避免混入身份迁移。

完整归档前快照是 `8923f49`，可在独立目录恢复原源码、配置及锁文件。当前工作区内不自动恢复或运行旧入口，也不使用真实数据执行旧测试。

## 后续迭代

下一项建议是 CLI 聊天入口：复用共享客户端与正式认证，支持会话列表、发送、观察及取消，不再复制执行器。随后可增加来源授权管理界面，并展示当前授权范围和失败状态。

用户画像、语义记忆提取、共享会话、账号绑定和云端部署需单独定义权限、数据保留与验收。当前历史召回仍限定为有来源的原文检索；桌面、iOS、Android 保持暂停。

## 验证

默认测试保留模型与工具契约、任务恢复、取消与迟到结果、身份隔离、来源授权、旧表保留、进程锁及 API 测试。新增边界检查和每次执行的搜索预算、来源状态隔离验证。旧 QQ 测试移出后，默认测试数量下降，不以跳过或降低要求代替验证。

验证结果：核心与客户端类型检查、Web 构建、`git diff --check` 通过；活动核心测试 72 项、客户端 6 项、浏览器 6 项通过，无跳过。涉及本机监听和进程身份的测试在沙箱外运行。归档前第三期完整核心测试为 382 项，归档后不再执行旧群聊行为测试。

归档源码与配置逐字节对照 `8923f49` 检查，日志与检查记录保存在忽略目录 `artifacts/phase-4/`。文档已核对标题、敏感信息、链接和实现事实。
