# 工作台来源授权管理

2026-10-28。工作台对话标题旁的“来源授权”打开当前会话的管理面板。管理设备可选择、保存和撤销跨会话来源，普通设备只读。授权默认不扩大，也不会自动打开服务端的记忆能力。

## 使用方式

面板明确显示当前目标会话、已确认的授权和尚未保存的选择。可选项只包括同一拥有者的其他直聊会话，最多 8 个；当前会话自身不需要授权。勾选后点击“保存授权”才生效，“撤销全部来源”会清空当前目标的跨会话授权。

授权是单向的。允许 A 读取 B，不会自动允许 B 读取 A；实际召回仍由服务端记忆配置控制。新建会话不会被自动勾选。重新加载时同时读取最新授权和会话列表；旧授权指向已不可用的来源时仍显示该项，允许用户明确撤销，不静默扩大或清理授权。

切换会话、账号或服务地址后，面板使用新的请求范围，旧读取和保存响应不会写进新会话的界面。关闭面板不撤销已经提交的保存请求，再次打开会重新读取服务状态。

## 保存、失败与多设备冲突

| 状态 | 界面行为 |
| --- | --- |
| 初次读取中或失败 | 禁止编辑；显示加载或错误，允许重新加载 |
| 有未保存选择 | 已授权列表维持原值；保存按钮可用，草稿不当成授权 |
| 保存成功 | 以服务返回的完整列表更新界面，并显示成功状态 |
| 网络结果不确定 | 不显示成功，标记上次确认的列表；禁止再次提交，需重新加载核对 |
| 权限失效 | 显示无修改权限，不显示成功，保留只读的上次结果 |
| 其他设备已修改 | 返回版本冲突；不覆盖新列表、不自动重试，需重新加载后重新选择 |

界面通过共享 SDK 的 `setMemorySources(id, ids, expectedRevision)` 保存。API 在事务中比较授权版本，不相同返回 409 和 memory_policy_conflict；非法版本返回 400。未提供版本的旧 SDK/CLI 调用继续兼容原有整体替换行为。

未修改记忆读取规则、身份认证或旧数据。来源归属和管理权限仍由后端检查；隐藏普通设备的编辑控件不能替代服务器权限校验。

## 验证与限制

浏览器用例覆盖保存、刷新后持久结果、撤销、普通设备只读、来源范围、8 项上限、新会话不自动授权、不可用来源、读取及保存失败、多设备冲突、会话切换时的迟到响应，以及权限失效。1280、390 和 320 像素宽度检查长标题、无横向溢出及消息输入框仍在视口内。

后端用例检查陈旧版本不能覆盖新授权或撤销新列表；SDK 用例检查版本参数和写入不自动重试。验证只使用测试身份、浏览器请求夹具和临时数据库，不操作真实账号或模型。

面板提供显式重新加载，不轮询或自动合并其他设备的改动。新建共享会话、成员授权、语义记忆和互动式 CLI 均不属于本次范围。

验证结果：核心测试 78 项、客户端测试 7 项、浏览器测试 16 项通过，无跳过；核心与客户端类型检查、Web 构建及 `git diff --check` 通过。浏览器中有 10 项来源授权用例，截图和日志保存在忽略目录 `artifacts/source-permissions/`，已检查桌面及窄屏截图。文档已核对标题、敏感信息、链接和实现事实。
