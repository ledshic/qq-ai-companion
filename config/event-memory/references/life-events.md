# 生活事件示例

## 休假与复工

“明天开始休两天，周一上班”：可提取休假区间和单独的上班里程碑。原文支持时，可在 followup 中选择上班里程碑的索引，建议询问当天近况；时间语义上，上班里程碑不得早于明确说出的假期结束，可设置 notBeforeEnd 约束。

“明天休两天”：可提取区间，区间结束后可提出“问问休息得如何、是否恢复日常”的推断型关注，不能写成周一确定上班。

“放两天假”：没有开始日期，不能推算今天复工。“要是能放两天假就好了”是愿望；“他说他休假”是第三方转述，不作为说话人本人的事实。引号里的话不自动成为本人事实。

“改成下周才休”：仅在能明确对应原事件时更正，日期不清则取消旧日期机会，不猜新日期。

## 学习与考试

“我下周三考试”：可提取本人考试计划和考试日期。可提出当天询问准备情况的关注，但不要声称考试已结束或通过。考后交流需要另有时间依据；不从考试日期编造具体结束时刻。

“如果能考过就好了”是愿望，不是已经通过。别人讨论考试不代表本人参加。

## 项目与个人计划

“我明天开始做模型，计划花三天”：可提取计划区间，结束时可询问进展；计划结束不代表任务已完成。

“周五发版”：必须确认是本人负责或本人明确计划，不能把团队讨论直接算作个人承诺。可关注约定日期，不编造已发布结果。

## 旅行与兴趣活动

“明天去露营，两天后回来”：可提取行程和明确回程里程碑，回程与恢复工作是不同事实。

“下周六参加比赛”：可提取活动计划，询问期待或准备；不能推断比赛结果。参考中的态度不决定人物关系和调侃许可。
